1. Demand observations

CSV: date,store_id,demand. Exactly three stores, 20–160 dates, one category, consistent time intervals. ISO dates sort chronologically. The bundled CSV of means/CVs is not training data.

2. Reference and LLM rules

Fixed reference: priority_floor 0.9, base_floor 0.6, emergency false. Editing the instructions changes the translation task only. To compare a different policy, the reference must be revised in a future version.Open ChatGPTExplicit copy/paste handoff. No simulated LLM response and no API integration.
